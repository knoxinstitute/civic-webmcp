# Civic WebMCP Principles

Civic WebMCP is built around a simple conviction: technology should increase a person's capacity to understand public questions and exercise informed judgment, not obscure the sources, assumptions, or disagreements that judgment depends on.

## 1. Provenance before persuasion

A policy claim is more useful when a human or agent can inspect where it came from.

Civic WebMCP treats provenance as part of the content itself. Legal text, official data, empirical research, organizational analysis, and commentary should not collapse into an undifferentiated answer.

## 2. Facts, analysis, projections, and values are different things

Public-policy arguments routinely move among empirical observations, causal analysis, forecasts, and normative judgments. Those categories can all be legitimate, but they are not interchangeable.

The profile makes the category explicit so agents can preserve the distinction in downstream answers.

## 3. Disagreement is data

Policy disagreement should be attributable and inspectable.

`civic_get_positions` exists to let publishers represent real perspectives and source them. It is not a requirement to invent symmetry where the evidence is asymmetric, and it is not an instruction for an agent to treat every claim as equally credible.

## 4. Humans retain civic agency

AI can lower the cost of research, comparison, source tracing, and understanding procedural opportunities. It should not silently turn those capabilities into automated political action.

The v0.1 profile is intentionally read-only. Participation tools describe opportunities for humans; they do not submit comments, send political messages, or make civic commitments without deliberate human action.

## 5. The open web remains the source of record

Civic institutions should not have to surrender their public knowledge to a proprietary AI database in order to be useful in an agentic world.

WebMCP allows the public website itself to publish an agent interface. The human page, structured data, citations, and agent tools can therefore remain part of one public source.

## 6. Shared context is better than invisible automation

The best human-agent civic workflows allow the person to see the same resource the agent is using. When an agent selects a resource or filters a policy collection, the visible website can update in parallel.

That shared state helps make the agent's work legible.

## 7. Interoperability compounds civic value

Civic WebMCP should complement established civic and legal data standards rather than replace them. A mature ecosystem can map Open Civic Data, Popolo, Schema.org, Akoma Ntoso, government APIs, and publisher-specific research into a consistent agent-facing surface.
