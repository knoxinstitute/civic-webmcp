# PolicyMCP.org

PolicyMCP.org is the public-facing home of the Civic WebMCP project.

- **PolicyMCP** is the public project identity and domain.
- **Civic WebMCP** is the open technical profile for agent-ready public-policy websites.
- **Knox Policy Lab** is the reference implementation included in this repository.

The site is built from this repository with Vite and deployed through the `Deploy GitHub Pages` GitHub Actions workflow.

The custom domain is configured in the repository's GitHub Pages settings. With an Actions-based Pages deployment, GitHub does not infer the custom domain from a `CNAME` file in the repository.
